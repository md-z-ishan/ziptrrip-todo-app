# 🎯 Ziptrip Premium Todo Application

Full-stack interview-quality todo app with premium features.

## Features
- ✅ CRUD operations
- ✅ Priority levels (High/Medium/Low)
- ✅ Categories & Tags
- ✅ Due dates with countdown
- ✅ Statistics dashboard
- ✅ Dark mode
- ✅ Responsive (390px-1440px)
- ✅ Search & Filter
- ✅ Smooth animations

## Quick Start

```bash
npm run install-all
npm run dev
```

Backend: localhost:5000
Frontend: localhost:3000

## Tech Stack
- Frontend: React 18 + Vite + React Router v6
- Backend: Node.js + Express
- Database: JSON file storage
